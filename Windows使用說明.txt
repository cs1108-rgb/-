衡序 MeasureOS｜Windows 本機版
=============================

一、首次準備
1. 從 https://nodejs.org 安裝 Node.js 24 LTS，保留安裝程式的預設選項。
2. 將下載的 ZIP「全部解壓縮」到你的電腦，例如：C:\MeasureOS。
   不要直接在 ZIP 內執行，也建議避開公用或雲端同步的資料夾。
3. 雙擊 SETUP-WINDOWS.cmd，等待安裝與建置完成。
   首次安裝需要網路以下載套件；不需要上傳文章。
4. 雙擊 START-WINDOWS.cmd。第一次直接執行此檔也會自動完成安裝。
5. 瀏覽器會自動開啟 http://127.0.0.1:3000 。
   如果沒有自動開啟，請將該網址輸入 Edge 或 Chrome。

二、上傳與檢核
1. 在網頁點「新增文章檢核」。
2. 選擇刊期月份，選擇要檢查的 Word（.docx）文章。
3. 點「開始檢核」，查看錯誤、警告與待人工確認項目。
4. 每個問題包含段落位置、文字摘錄及修改建議。
5. 修正原稿後重新上傳，新結果會以另一筆紀錄保存。
6. 「歷史紀錄」可查閱過往結果、下載原稿或匯出報告。
7. 「檢核規則」可開關規則；停用規則不代表通過。

三、關閉與再次使用
- 使用期間保留黑色命令視窗開啟。
- 按 Ctrl+C 停止服務，或關閉命令視窗。
- 下次雙擊 START-WINDOWS.cmd 即可，無需重複安裝。
- 關閉服務不會刪除歷史資料。

四、資料保存與備份
- 本機啟動檔僅允許本電腦透過 127.0.0.1 連線，沒有發布到公開網站。
- 執行時文章由本機瀏覽器送至本機 Node.js 服務，不使用外部 AI 或雲端檢核服務。
- 原始 Word、檢核結果與規則都在 data\measurements.sqlite。
- 備份前停止服務，再複製整個 data 資料夾到安全位置。
- 資料庫沒有加密；請保護電腦帳號和備份存取權限。
- 更新程式前先備份；請保留 data 資料夾，勿以空白資料庫覆蓋。

五、常見問題
- 找不到 Node.js：安裝 Node.js 24 LTS 後，重新開啟啟動檔。
- 套件下載失敗：確認網路與公司代理設定後，重跑 SETUP-WINDOWS.cmd。
  不要關閉 TLS 或套件驗證。安裝成功後，日常檢核不需網路。
- 3000 埠被占用：先關閉另一個啟動視窗。
  也可在命令提示字元進入程式資料夾後執行：
    set PORT=3001
    START-WINDOWS.cmd
- Windows SmartScreen：僅在確認下載來源可信並核對檔案後再執行。
  若公司政策禁止 CMD 或安裝 Node.js，請交由資訊人員協助，不要繞過政策。
- 網頁無法連線：確認命令視窗沒有被關閉或顯示錯誤。

六、檢核範圍
依你提供的「1-表單-量測資訊撰文格式.docx」檢查文章，不是量測數值表格。
支援 .docx；舊版 .doc 請先另存。單檔上限 10 MB。
字體、字級、段落、章節與圖表引用提供自動判斷。
文獻正確性、未標題摘要、浮動圖片、線條圖類型及最終版面仍需人工確認。
自動符合率不等於出版核可。

驗證說明：程式與啟動流程已在 Linux 雲端環境驗證；目前無 Windows 主機，
因此尚未實測 Windows CMD 的雙擊啟動與預設瀏覽器開啟行為。
